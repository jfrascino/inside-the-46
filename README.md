# Inside the 46

An interactive, visual atlas of 27 chromosome conditions for middle-school science, built as a 5-step mission: fly from a cell down to its DNA, watch how an extra chromosome can happen, explore 27 conditions animated with real 3D chromosomes, build your own chromosome change in the Lab, and play karyotype games. Includes a teacher guide.

**Open it:** https://jfrascino.github.io/inside-the-46/

The whole app is one self-contained file (`index.html`), so it also works offline: download it and open it in any browser. Computers that can't show 3D automatically get a flat version.

Educational resource only, not medical advice. Facts were checked against MedlinePlus Genetics, the CDC, NIH, GeneReviews and ClinGen (September 2026). Chromosome bands come from the GRCh38 reference genome. 3D rendering uses three.js (MIT license).
