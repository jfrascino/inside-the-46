# Inside the 46

An interactive, visual atlas of 27 chromosome conditions for middle-school science: animated chromosome changes, a karyotype lab built from real human-genome band data, a meiosis simulator, games, and a teacher guide.

**Open it:** https://jfrascino.github.io/inside-the-46/

The whole app is one self-contained file (`index.html`), so it also works offline: download it and open it in any browser.

Educational resource only, not medical advice. Facts were checked against MedlinePlus Genetics, the CDC, NIH, GeneReviews and ClinGen (September 2026).
